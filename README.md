# Aether SSH Viewer (Notion-Style UI)

SSH / SFTP をベースにした、**「閲覧とダウンロードに特化した（Read-Onlyで安全な）」** GUI ファイルエクスプローラーです。  
デザインは Notion のようなシンプルで美しいミニマルデザインを採用し、快適でスタイリッシュなファイル閲覧・プレビュー体験を提供します。

---

## 🖥️ 【Windows対応】1クリック インストーラー＆起動方法

Windows パソコンで手軽に使い始められるよう、専用の自動インストーラーをご用意しました！

### 1️⃣ 初回セットアップ（インストール）
フォルダ内の **`Setup_Windows.bat`** をダブルクリックしてください。
- 必要なサーバープログラムとUIコンポーネントが自動的にインストール・最適化ビルドされます。
- さらに、**Windows デスクトップに「Aether SSH Viewer」のショートカットアイコンを自動作成**します！

### 2️⃣ アプリの起動
デスクトップにできたショートカットアイコン、または **`Start_Windows.bat`** をダブルクリックするだけ！
- バックグラウンドで軽量APIサーバー（ポート3001）が静かに起動し、**自動的にデフォルトブラウザ（EdgeやChrome）でNotion風画面が開きます。**

---

## 🐧 【Ubuntu / Linux 対応】1クリック インストーラー＆起動方法

Ubuntu や Linux パソコンで快適に利用できるように、自動インストーラーと1クリック起動機能をご用意しました！

### 1️⃣ 初回セットアップ（インストール）
ターミナルを開き、以下のコマンドを実行するだけです：
```bash
cd /home/saito/Documents/ssh-file-viewer
./setup_ubuntu.sh
```
- 必要な Node.js パッケージのインストールと、最適化された静的UIビルドが自動で行われます。
- さらに、**デスクトップとアプリケーションメニューに「Aether SSH Viewer」のショートカットアイコンを自動作成**します！

### 2️⃣ アプリの起動
以下のいずれかから簡単に起動できます！
- **デスクトップのアイコンから起動**: デスクトップの「Aether SSH Viewer」アイコンをダブルクリック（※Ubuntuのバージョンによっては、アイコンを右クリックして「起動を許可 (Allow Launching)」を選択してください）。
- **アプリメニューから起動**: Ubuntu のアクティビティ／アプリ一覧から「Aether SSH Viewer」を検索してクリック。
- **ターミナルから起動**:
  ```bash
  cd /home/saito/Documents/ssh-file-viewer
  ./start_ubuntu.sh
  ```
※ バックグラウンドでサーバー（ポート3001）が起動し、**自動的にデフォルトブラウザでNotion風画面が開きます！**

## ✨ 主な機能と特徴

### 🛡️ 1. Read-Only（編集なし・閲覧専門）の安心設計
- サーバー上のファイルを誤って上書き・削除する機能をあえて排除。
- 本番サーバーや重要なログ、データセットなども**絶対に書き換える心配なく安全に閲覧・ダウンロード**できます。

### 🎨 2. Notion風 ミニマルデザインシステム
- **美しい余白とタイポグラフィ**: 余計な装飾を排し、コンテンツに没入できるシンプルなUI。
- **ライト＆ダークモード切替**: 右上のアイコンから、Notion同様の上品なライト/ダークテーマを瞬時に切り替え可能。
- **インタラクティブなファイルツリー**: 階層的な折りたたみと、ファイル種類別（画像・MD・JSON・コード等）の洗練されたアイコン表示。
- **接続履歴**: 過去の接続先を保存し、次回からワンクリックで接続。

### 👁️ 3. リッチプレビュー専門機能
- **🖼️ 画像ビューア**: PNG, JPG, GIF, WEBP, SVG に対応。ズームイン／アウト、実寸表示、回転、透過画像の背景切り替え（白／黒／チェック柄）機能。
- **📝 Markdown ビューア**: `.md` ファイルを単なるテキストではなく、Notionのページを読んでいるかのように美しいドキュメントとしてリアルタイムレンダリング（GFM・シンタックスハイライト対応）。
- **📊 データ構造（JSON / CSV）ビューア**:
  - **JSON**: ツリーを折りたたみながら構造を探索できるインタラクティブなビューアー。
  - **CSV / TSV**: スプレッドシート風の綺麗なテーブルフォーマットで表示。
- **📄 シンタックスハイライト**: ログファイルや各種コード（JS, Python, Go, Rust など）をカラーリング表示。
- **💾 ワンクリックダウンロード**: ブラウザの標準保存ダイアログですぐにローカルへダウンロード。
